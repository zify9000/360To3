# gaokao-360To3 — 从 360 行中，挑出最适合你的 3 个

> 一个运行在 Claude Code 中的高考志愿填报助手。

## 为什么需要它

填志愿时面对 800+ 专业、20 个行业门类，信息差比分数差更致命。家长用经验选，学生凭感觉选——结果往往不是最优解。

## 它做什么

**三层结构化对话**，像资深规划师一样逐步深入：

1. **摸家底** — 经济、人脉、地域、学历期望，厘清你的托举资源
2. **挖自己** — 学科强弱、心流模式、认知偏好、角色镜像，交叉验证你的天赋坐标
3. **算匹配** — 基于 2026 年权威就业数据 + 五维度加权评分，输出 3 个精准方向

## 亮点

- 📊 数据驱动而非经验驱动 — 所有引用来自教育部专业目录、麦可思就业蓝皮书
- 🎯 不是泛泛而谈 — 每个推荐对应具体专业、城市、薪资、风险提示
- 🔧 运行在 Claude Code 中 — `/gaokao-360To3` 即开即用，无需安装

> 专业不是手铐，选一条你不排斥、有成长的赛道，比「最完美」重要得多。
