> 来源：麦可思研究院《2026年中国大学生就业报告》

| 植物保护 | 行业体量小，市场化岗位稀缺 |
| 生态学 | 学术导向，本科就业口径窄 |
| 信息与计算科学 | 被纯数学和计算机两端挤压，定位尴尬 |

| 材料物理 | 纯理科材料方向，产业对口不如材料科学与工程 |
| 建筑学 | 房地产下行，建筑设计院缩招严重 |
| 纺织工程 | 传统产业外迁，国内高端岗位有限 |

## 六、各门类典型就业出口简述

| 门类 | 典型就业出口 |
|------|------------|
| 理学（数学/物理/化学） | 教师、科研院所、跨考工科/金融研究生有优势 |
| 工学 | 就业面最广，硬科技方向薪资溢价明显 |
| 医学 | 学历门槛高（硕士起步），但就业确定性强、社会地位高 |
| 经济学/管理学 | 银行/证券/企业财务/考公，头部名校溢价极高 |
| 法学 | 通过法考后律师/法务/考公，法考通过率约15%是硬门槛 |
| 文学/历史学/哲学 | 教师/公务员/媒体/企业文职，需辅修硬技能提升竞争力 |
| 教育学 | 中小学教师（编制稳定但竞争激烈）、教育科技公司 |
| 农学 | 农业科技企业、科研院所、基层农技推广 |
| 艺术学 | 自由职业/文化机构/设计公司，收入方差极大 |
| 交叉学科 | 新兴方向，就业模式尚在形成中，首批毕业生预计受前沿科技企业高度关注 |
