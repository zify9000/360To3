# 天赋→方向 匹配评分框架

> 用途：在阶段三中，为候选方向池中的每个方向计算加权得分，排序取前 3。

## 一、五维度评分锚

每个维度打 1-5 分。以下为各分数段的判断标准：

### 1. 能力匹配度（权重 0.30）

| 分数 | 标准 |
|:---:|------|
| 5 | 该方向核心能力与孩子的强势科目高度重合（如物理+数学双强 → 微电子/自动化） |
| 4 | 强势科目与该方向基本匹配，有 1 门弱科但可通过大学选课规避 |
| 3 | 科目不突出但也不劣势，属于"能学"的范畴 |
| 2 | 至少 1 门核心科目是孩子的弱科（如数学挣扎但选了金融） |
| 1 | 核心科目与孩子弱科严重冲突，大概率学不下去 |

### 2. 兴趣匹配度（权重 0.25）

| 分数 | 标准 |
|:---:|------|
| 5 | 心流活动与该方向日常工作模式高度一致（如喜欢拆东西 → 机械/硬件工程） |
| 4 | 心流活动部分匹配，职业日常中有 1-2 个乐趣点与孩子吻合 |
| 3 | 不排斥，心流活动与该方向关系不大 |
| 2 | 心流活动与该方向工作模式明显冲突（如讨厌重复却选了会计） |
| 1 | 孩子明确表达对该方向的抵触 |

### 3. 资源利用度（权重 0.20）

| 分数 | 标准 |
|:---:|------|
| 5 | 父母/近亲在该行业有直接人脉，能提供实习或入行绿色通道 |
| 4 | 父母在该行业上下游或相关体制内有资源，间接可借力 |
| 3 | 家庭资源与该方向无关，但不构成阻碍 |
| 2 | 家庭经济紧张 + 该方向初始投入高（如需要自费读研/出国才能入行） |
| 1 | 家庭明确反对该方向或该方向要求的地域/资源家庭完全无法支撑 |

### 4. 就业确定度（权重 0.15）

| 分数 | 标准 |
|:---:|------|
| 5 | 绿牌专业，招聘增速 > 20%，长期人才缺口明确 |
| 4 | 行业招聘正增长，非绿牌但就业稳定（如教师、电力） |
| 3 | 行业需求平稳，供给基本平衡 |
| 2 | 黄牌专业，供给过剩或行业下行 |
| 1 | 红牌专业，就业落实率 < 70% |

### 5. 学历适配度（权重 0.10）

| 分数 | 标准 |
|:---:|------|
| 5 | 家庭学历期望与该方向完美匹配（如期望本科就业 → 选了电气/电网方向） |
| 4 | 基本匹配，方向对学历要求略高于家庭期望但可接受 |
| 3 | 方向学历门槛与家庭期望不冲突 |
| 2 | 方向需要比家庭预期更高的学历（如期望本科但选了临床医学） |
| 1 | 方向学历要求与家庭期望严重对立 |

## 二、考分档次硬过滤

在评分前，根据学生的高考分数档次，将不可及的方向直接排除。

| 分数档次 | 代码 | 可触及方向范围 | 排除规则 |
|---------|:---:|--------------|---------|
| 清北/华五 | L0 | 全部方向，含量子科技、脑机接口、核聚变等前沿学科 | 无排除 |
| 985 | L1 | 绝大部分方向，前沿学科可走但需顶尖GPA | 核聚变等极前沿方向标记为"高风险" |
| 211 | L2 | 硬科技+体制内稳妥方向，基础IT/金融仍有空间 | 量子科技、脑机接口等标注"不建议" |
| 普通一本 | L3 | 电气/电网、机械、师范、护理、会计、考公友好专业 | 排除：量子科技、脑机接口、核聚变、航空航天（设计岗）、金融（头部机构） |
| 二本 | L4 | 体制内（考公/考编）、技能型工科（机械/电气）、护理、教育、会计 | 排除：所有前沿科技方向、医学（临床/口腔）、金融（投行/券商）、科研导向 |
| 专科 | L5 | 技能型+体制内基层，技术蓝领方向 | 排除：绝大多数需要硕士以上的方向，聚焦高职对口专业 |

### 过滤流程
1. 阶段一收集考分档次
2. 阶段三评分前，先筛掉该档次「不可触及」的方向
3. 剩下的方向再进入五维评分

## 三、加权公式

```
总分 = 能力匹配度 × 0.30
     + 兴趣匹配度 × 0.25
     + 资源利用度 × 0.20
     + 就业确定度 × 0.15
     + 学历适配度 × 0.10
```

取总分最高的 3 个方向作为推荐。

## 四、调分规则

| 触发条件 | 调整 |
|---------|------|
| 考分档次不达标 | 该方向直接排除（见第二节硬过滤表） |
| 家庭经济 ≤10万 + 方向依赖出国（如纯理科需海外 PhD） | 就业确定度 × 0.5 |
| 地域约束"必须回本省" + 本省无该产业聚集 | 能力匹配度 × 0.7 |
| 连续 2 轮答不出（数据缺失） | 兴趣匹配度权重从 0.25 降至 0.15，能力匹配度升至 0.35，就业确定度升至 0.20 |
| 家长明确禁止某个方向 | 该方向直接排除，不参与评分 |
| 方向属高子弟壁垒行业（见第八节）+ 考生无该行业背景 | 资源利用度上限降为 2，就业确定度 × 0.85 |

## 七、风险偏好 → 方向筛选

根据阶段一收集的风险偏好，对候选方向进行二次过滤：

| 风险偏好 | 筛选规则 |
|---------|---------|
| **体制内优先** | 保留体制友好度 ★★★ 的方向，★★ 方向降权 0.3，★ 方向降权 0.5 |
| **企业挣钱优先** | 不设体制偏好过滤，就业确定度权重提升至 0.25（从 0.15），学历适配度降至 0.05 |
| **都行** | 不设额外过滤，按原始评分 |

### 体制内热门专业类（直接加分）
法学类、马克思主义理论类、中国语言文学类、公共管理类、电气类、临床医学类、护理学类、教育学类、公安学类

> 详细数据见 `employment.md` 第七节。本节将壁垒映射到方向池中的具体方向，供阶段三评分引擎交叉检索。
